# Release Notes

This directory contains release notes for each version of Panopticon.

## Format

Each release note file follows the format: `vX.Y.Z.md`

## Versions

- [v0.1.0](./v0.1.0.md) - Initial Release (November 17, 2025)

## Creating Release Notes

When preparing a new release:

1. Create a new file: `release-notes/vX.Y.Z.md`
2. Follow the template structure from previous releases
3. Include:
   - Release date
   - New features
   - Bug fixes
   - Breaking changes (if any)
   - Known issues
   - Installation instructions

## Using Release Notes

When creating a GitHub release:

1. Copy the content from the appropriate markdown file
2. Paste into the GitHub release description
3. Attach the built `.exe` file
4. Tag the release with the version number (e.g., `v0.1.0`)
